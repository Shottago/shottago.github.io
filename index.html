n8n Feedback Automation

This is a private, internal automation used by a single QA engineer. It reads app-feedback summary e-mails, generates daily reports, and stores report files in the owner's own Google Drive.

本應用程式僅供內部 QA 自動化使用：整理 App 使用者回饋摘要、產生每日報告，並將報告檔案存放於擁有者本人的 Google Drive。不對外提供服務。
