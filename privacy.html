Privacy Policy — n8n Feedback Automation

Last updated: 2026-10-27

What this app accesses

The app uses Google Drive access granted by its owner only. It creates, reads, and moves report files (JSON and PDF) in folders that belong to the owner's own Google Drive account.

How data is used

Data is used solely to run the owner's internal QA reporting workflows. It is not sold, shared with third parties, or used for advertising.

Storage and retention

Files stay in the owner's Google Drive and the owner's self-hosted n8n server. The owner can delete them, or revoke access at any time at https://myaccount.google.com/permissions.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
